## 1. Working agreement

- **Claude writes, Codex reviews, the owner decides.** Every PR gets
  `@codex review` until it has no findings.
- **Merging:** the owner merges, or tells Claude to, PR by PR. Merging into
  `main` deploys to **production** on Vercel within about a minute.
- **Database:** every change is a numbered file in `supabase/migrations/`.
  - Local Supabase: Claude may apply and test freely (`supabase db reset
    --local`; tests in `supabase/tests/`).
  - Staging: with the owner's OK.
  - Production: only with the owner's OK, each time.
- **Before each push:** `npx tsc --noEmit`, `npm run lint`, `npm test`,
  `npm run build`. CI runs the same plus the browser tests on every PR.
- **Contact and language rules:** CLAUDE.md and AGENTS.md;
  Indonesian wording: `docs/indonesian-glossary.md`.
