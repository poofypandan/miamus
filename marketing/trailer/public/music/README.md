# MUSIC SLOT

No track is licensed yet, so every render so far is silent, captions only.

To add one: put a track whose licence covers advertising on social platforms
here (for example `track.mp3`), keep its licence document beside it, then:

    npm run render -- --music=music/track.mp3

The storyboard's brief: light, warm, unhurried; a soft plucked or marimba line
over a gentle pulse, 96–104 BPM, no vocals. It drops to almost nothing under
shot 8 (0:45–0:52) and comes back for the end card; the composition does that
ducking itself (src/Trailer.tsx, the Audio volume curve).
